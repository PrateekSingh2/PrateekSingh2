### ⚡ [AlgoLib v3.1](https://algolib.netlify.app) — Algorithm Learning & Competitive Coding Ecosystem

|---|---|
| 🎯 **DSA Visualizer** | Interactive pathfinding, sorting & binary tree animations with step-by-step breakdowns |
| 💻 **Online Compiler** | Multi-language code execution engine — C++, Python, Java, JavaScript |
| 🏆 **Contest Engine** | Timed live contest environments with real-time leaderboard and scoring |
| 🧠 **Quiz Engine** | Gamified algorithmic quiz system with difficulty progression and badges |

**Stack:** `React` · `Node.js` · `MongoDB` · `Tailwind CSS` · `REST API` · `Netlify`

> **Prompt → Production form in seconds.** Natural language to fully validated, shareable forms with instant API endpoints.

- 🧠 Generative AI schema compilation from plain-English prompts  
- ⚡ Real-time form preview with dynamic validation and conditional logic  
- 🔗 Shareable links + embeddable form endpoints generated instantly  
- 🎨 No-code field customisation with live drag-and-drop editor  

**Stack:** `Next.js` · `TypeScript` · `Generative AI` · `Vercel Edge`
